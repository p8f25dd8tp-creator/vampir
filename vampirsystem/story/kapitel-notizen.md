# My Vampire System — Kapitelnotizen (eigene Zusammenfassungen, deutsch)

Arbeitsnotizen beim vollständigen Lesen des Romans. Nur eigene Worte, keine Textübernahmen.
Namen: Original (deutscher Name in Klammern, soweit bekannt).
Kürzel: **F** = Fähigkeit/System, **O** = Ort, **K** = Kampf, **NEU** = neue Figur.
